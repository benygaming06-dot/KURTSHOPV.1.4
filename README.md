# KURTSHOP INVENTORY V1.4

## Account & Role System
- Owner Shop Acc: full inventory control
- Assistant: full inventory control
- Mechanic Employee: can view products/services, add items to cart, checkout, generate receipts, and view sales history; cannot edit/delete/add inventory or change stock.

Default accounts:
- owner / owner123
- assistant / assistant123
- mechanic / mechanic123

Accounts and inventory are stored locally on the device. Owner/Assistant can manage user accounts and change passwords from Settings.
